Overview

Frontier vision–language models can reason about scenes, invoke robot tools, and adapt to execution feedback, but repeated model calls incur high costs and latency. Guava transfers these capabilities to a compact agent through a shared manipulation harness and simulation-generated interaction data. Using GPT-5.4 as the teacher, we collect just over 2,000 trajectories and fine-tune Qwen3.5-4B to obtain Guava-4B. The compact agent approaches its frontier teacher across simulation, real-world, and external-benchmark evaluations, while substantially reducing inference latency and token usage.

A shared manipulation harness

The teacher and compact agent use the same observation, tool, and feedback interface. This lets teacher interaction histories serve directly as supervision for the student's subsequent decisions. We study three interface choices across GPT-5.4 and Qwen3.5-4B:

  1. Iterative perception–reasoning–action loops

    The full harness uses single-action replanning: a ReAct-style loop selects one action, executes it, then observes and replans. The multi-action replanning variant in the table instead generates a program of tool calls with simple control flow, executes it, then observes and generates another program if needed.

  2. Semantic action abstractions

    Object-referenced tools such as grasp and align encapsulate manipulation skills. The low-level comparison replaces semantic robot-control tools with a command specifying end-effector pose and gripper width.

  3. Multimodal observations

    RGB images, numerical gripper state, and tool-response text expose execution outcomes. We compare this full feedback with image-only and image-plus-gripper-state observations.

Training Guava-4B

GPT-5.4 generates interaction trajectories in randomized MuJoCo scenes through the shared harness. We also branch from saved states by injecting execution deviations, such as missed grasps or dropped objects, and retain successful recoveries. Simulator outcome labels undergo automated consistency checks and human visual review; supported annotation errors are corrected and unresolved episodes are excluded.

We fine-tune Qwen3.5-4B on the simulation trajectories, supervising the teacher's interleaved reasoning and tool calls in the context of observations and execution feedback. The resulting Guava-4B uses the same harness at deployment, without additional real-world fine-tuning.

Results

Guava-4B approaches GPT-5.4 performance while substantially outperforming its base model: 87.1% success in simulation and 90.0% in the real world, compared with 90.4% and 93.3% for GPT-5.4.

Failure recovery

Qualitative examples illustrate feedback-conditioned adaptation. When an object is displaced before grasp execution, Guava retries using the updated scene. In the controller example, the gripper contacts the box rim during can placement, causing an abort consistent with a Cartesian collision reflex. The agent repositions horizontally to clear the obstruction and resumes placement. Unlike the missed grasps and displaced objects represented in training, this interruption comes from the physical robot's safety controller stopping motion in response to contact. The simulation data did not include this controller-specific failure, so the example illustrates adaptation to unfamiliar execution feedback.

RL fine-tuning

Additional GRPO post-training improves success on shell game from 63.3% to 90.0% and on placing all red objects in a basket from 80.0% to 86.7%, over 30 trials per task. These results show further improvement on the two selected long-horizon tasks.

Efficient local inference

On a single RTX 5090, Guava-4B reduces mean model-call latency by 7.10× and generated tokens per episode by 66.7% relative to the GPT-5.4 API, while approaching the teacher's manipulation performance.
